# Архив Истока для браузера-киоска: как запустить

Эта инструкция лежит в каждом архиве для браузера и на сайте Истока в разделе «Обучение». Архив открывается в Google Chrome или Microsoft Edge на любом компьютере, сеть не нужна.

## 1. Распакуйте архив целиком

1. Скопируйте архив на компьютер стойки, например в папку C:\Стенд.
2. Правой кнопкой по архиву → «Извлечь всё…» → «Извлечь».
3. Откройте index.html из получившейся папки двойным кликом — стенд откроется в браузере.

Открывать index.html прямо из архива нельзя: браузер не увидит файлов рядом, и экраны останутся пустыми.

## 2. Режим киоска: во весь экран и без панелей браузера

В обычном окне посетитель увидит адресную строку и вкладки и уйдёт из стенда в браузер. Режим киоска убирает всё, кроме страницы.

Edge (есть в Windows 10 и 11):

1. Правой кнопкой по рабочему столу → «Создать» → «Ярлык».
2. В поле расположения вставьте одну строку, заменив путь на свой:
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --kiosk "file:///C:/Стенд/index.html" --edge-kiosk-type=fullscreen --no-first-run
3. Назовите ярлык «Стенд» и запускайте стенд им.

Chrome — то же, путь к программе другой:

   "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk "file:///C:/Стенд/index.html" --no-first-run

Выйти из режима киоска — Alt+F4 с подключённой клавиатуры.

## 3. Автозапуск при включении компьютера

1. Нажмите Win+R, введите shell:startup и нажмите Enter — откроется папка автозагрузки.
2. Скопируйте туда ярлык «Стенд» из шага 2.

Для ИТ-службы заказчика, чтобы стенд поднимался без людей: включите автоматический вход в Windows (Autologon от Microsoft Sysinternals или netplwiz), отключите сон в «Электропитании» и, если стенд выключается вместе с помещением, включите в BIOS «включение после пропадания питания» (Restore on AC Power Loss).

## Чего у браузера-киоска нет

Браузер — не приложение стойки. Он не перезапустит себя после сбоя, не обновит содержимое с флешки и не отдаст журнал посещений на флешку для отчёта. Всё это умеет «Приложение для Windows» — его собирают в том же окне сборки редактора.

## Обновить содержимое

Соберите новый архив и замените им содержимое папки стенда целиком, затем перезапустите ярлык.
